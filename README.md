### 👨‍💻 The Lowdown

Hey! I'm a Full-Stack Software Engineer who loves building systems from the ground up. Whether it's designing complex database architectures, writing clean APIs, or wiring up a solid frontend, I'm all about making things run flawlessly under the hood. 

- 🔭 **What I'm building:** A massive offline-first business ERP (teamed up with my friends on this one—I handled the frontend and core backend sync) and an ag-tech logistics platform called **Triumph Farms**.
- 🌱 **What I'm exploring:** Going down the rabbit hole of advanced database optimization, system architecture, and writing code that actually scales.
- 🎧 **Coding playlist:** Usually blasting a chaotic mix of Noah Kahan, Hozier, Leonard Cohen, and Chike. 
- 🛠️ **Open Source Flex:** I built a CSS selector generator extension for VS Code that somehow blew up to over 6,500+ downloads!
- 🎓 **IRL:** Grinding out my BSc. in Software Development (Class of '26).
