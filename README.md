### 👨‍💻 The Lowdown

Hey! I'm a Full-Stack Software Engineer who loves bridging the gap between heavy backend logic and ridiculously smooth, physics-based UI animations. If it has Neumorphism, Fluent Design, or complex database architecture, count me in. 

- 🔭 **What I'm building:** A massive offline-first business ERP (teamed up with my friends on this one—I led the UI/UX and core backend sync) and an ag-tech logistics platform called **Triumph Farms**.
- 🌱 **What I'm exploring:** Going down the rabbit hole of advanced database optimization and perfecting those buttery-smooth UI micro-interactions.
- 🎧 **Coding playlist:** Usually blasting a chaotic mix of Noah Kahan, Hozier, Leonard Cohen, and Chike. 
- 🛠️ **Open Source Flex:** I built a CSS selector generator extension for VS Code that somehow blew up to over 6,500+ downloads!
- 🎓 **IRL:** Grinding out my BSc. in Software Development (Class of '26).
